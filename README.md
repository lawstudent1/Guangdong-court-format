# 广东法院立案文书模板

广东省法院立案文书与材料清单整理库，按立案阶段和法院分别归档，便于查找和准备诉讼材料。

## 目录结构

- `01-一审立案`：民事、商事、行政、刑事自诉等一审立案材料
- `02-二审立案`：民事、行政、刑事上诉及相关材料
- `03-再审立案`：民事、行政再审申请和刑事申诉材料
- `04-执行立案`：首次执行、执行依据、恢复执行、执行异议及相关材料
- `00-按立案阶段选法院.html`：按阶段和法院查找材料的入口
- `00-法院归属核验报告.html`：模板来源法院和文件归属核验记录

每个法院目录内的 `00-本阶段材料清单.html` 会说明：

- 必须提交的材料
- 当事人自行准备的材料
- 委托代理、保全、诉讼费缓减免等条件性材料
- 本院现有模板和法院发布的立案指引

## 使用说明

1. 打开根目录的 `00-按立案阶段选法院.html`。
2. 选择一审、二审、再审或执行立案。
3. 选择具体法院，阅读该法院的材料清单。
4. 按案件类型和法院最新要求选择模板，并准备身份证明、裁判文书、证据等自备材料。

模板仅供整理、查找和填写参考。各法院的受理范围、提交份数、材料格式和在线立案要求可能更新，正式提交前应以受理法院官网、在线立案平台或立案窗口的现行要求为准。

## 整理范围

本库根据已收集的广东法院公开文件进行整理，并对文件名称、正文抬头、落款和来源记录进行归类核对。法院网站发布的历史文件、阅读指引和示范文本不一定都是当前案件的必交材料；清单中已尽量区分必交材料、条件性材料和阅读材料。
